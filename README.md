## 🛠️ Projetos - Imersão Alura + Google

### 1. 📊 ROI Marketing Pro
Aplicação interativa desenvolvida no **Google AI Studio** para auxílio na tomada de decisão em Marketing Tech.
- **Funcionalidades:** Cálculo automático de ROI (%), Lucro Líquido e Margem de Lucro, salvamento no navegador (`LocalStorage`), gerenciamento de histórico e exportação para CSV.
- **Tecnologias:** Google AI Studio, Gemini API, Engenharia de Prompts (GCCD), JavaScript, Tailwind CSS.

---

### 2. 🧮 Calculadora em Python (Desafios 1 & 2)
Aplicação em Python para cálculos matemáticos interativos.
- **Funcionalidades:** Operações básicas (Adição, Subtração, Multiplicação, Divisão) e módulo de **Cálculo de Porcentagem (%)**.
- **Tecnologias:** Python 3, Lógica de Programação.

---

### 3. 📌 Lista de Tarefas Interativa (Desafio 3)
Aplicação web interativa para organização pessoal e acompanhamento de atividades.
- **Funcionalidades:** Adição dinâmica de tarefas, sinalização visual de conclusão (`line-through`) e exclusão de itens.
- **Tecnologias:** HTML5, CSS3, JavaScript.
